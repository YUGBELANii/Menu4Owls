Normal schedule

Automatic · Asia/KolkataOpen daily at 6:00 PM and close at 3:00 AM, including the after-midnight period.

The customer site and checkout currently use this clock-based schedule. Leaving the admin panel unchanged preserves current behaviour.

Temporary overrides need shared storage

There is no persisted store-settings record or API for overrides and editable customer messages. I have not added browser-local controls because those would affect only this admin browser and would not reliably update the public site. A safe implementation needs one shared settings record for mode, override start/end, opening time, expiry, and separate open/closed/late messages, plus a single Asia/Kolkata status evaluator used by both the storefront and checkout.

That evaluator must handle automatic hours, opening late, closed today, temporary closure, immediate reopen, expiry, and reset to Normal Schedule without changing the default 6:00 PM–3:00 AM schedule.
